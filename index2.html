구글 시트 → 노션 자동화 · Apps Script

오늘 만들 것 · 나의 강의 대시보드

시트에 강의 정보를 적으면 노션에 강의계획서가 생기고, AI가 지도안까지 채웁니다.

메뉴하는 일
노션DB · 보기 · 수식 · 버튼으로 코드 없이 정리
시트 연결시트에 있는 자료를 노션으로
AI 지도안채워진 내용으로 AI가 지도안 작성
1

새 페이지 · 데이터베이스 추가

강의를 담을 페이지와 표를 먼저 만듭니다.

순서하는 일
1좌측 사이드바 + → 새 페이지
2제목 : 나의 강의 대시보드
3본문에 /데이터베이스 → 인라인 선택
4DB 이름 : 강의 DB
전체 페이지가 아니라 인라인으로 만듭니다.
7번에서 버튼을 DB 위에 놓아야 하는데, 전체 페이지 DB에는 블록을 놓을 자리가 없습니다.
2

노션 DB 속성

이름과 타입이 정확히 같아야 합니다.

순번속성명노션 타입시트 열

2대상텍스트B
3강의날짜날짜C
4차시텍스트 (숫자 아님)D

3

구조 확인용 데이터 입력

속성을 다 만든 뒤, 뷰가 보이도록 한 건만 넣습니다.

예시 1건

강의명캔바로 만드는 수업 안내문
대상초등 교사 (캔바 처음)
강의날짜2026-11-28
차시1
상태준비중
수업주제 · 수업목표 · 수업내용 · 비고는 비워 둡니다.
캘린더 · 보드 보기를 확인하는 데는 날짜와 상태만 있으면 됩니다. 내용이 모두 채워진 강의는 시트 연결에서 보냅니다.
4

보기 — 표 · 캘린더 · 보드

같은 데이터를 세 가지 모습으로 봅니다.

보기보여주는 것언제 쓰나
표모든 속성을 한 줄에 펼쳐서내용을 입력하고 고칠 때
캘린더강의날짜 를 달력 위에강의가 언제 몰려 있는지 볼 때
보드상태 별로 칸을 나눠 카드로준비 진행 상황을 볼 때
데이터는 하나입니다. 옮기거나 복사한 게 아니라 보는 방식만 바뀝니다.
표에서는 할 수 없던 일이고, 이것이 표와 데이터베이스의 차이입니다.
5

D-day 속성 추가

표 맨 오른쪽 + → 유형 수식 → 이름 D-day → 아래 수식 붙여넣기

수식 — 그대로 붙여넣기

now() 가 아니라 today() 입니다. now() 에는 시각이 들어 있어 하루가 모자라게 나옵니다.

직접 만들어 보려면 — AI에게 물어볼 프롬프트

완성 수식과 생김새가 달라도 결과가 같으면 맞습니다. 오류가 나면 “노션 수식 2.0 문법이 맞는지 확인해줘” 라고 다시 물어보세요.

6

템플릿 만들기

버튼으로 만드는 페이지에 들어갈 양식입니다.

순서하는 일
1강의 DB 우측 상단 새로 만들기 옆 ∨ → 새 템플릿
2제목 : 템플릿1 — 템플릿 이름이 됩니다. 새 페이지 제목은 버튼에서 비웁니다
3속성 칸도 비워 둡니다 — 강의명 · 날짜는 매번 다르니까요
4본문에만 아래 네 줄 입력

본문에 넣을 네 줄

템플릿에는 값을 넣지 않습니다. 매번 똑같이 적어야 하는 항목 이름만 미리 넣어 두는 것입니다.
🎯 지도안 은 비워 둡니다. 오후에 AI가 채우는 칸입니다.
제목을 템플릿1 로 적으면 다음 단계 버튼에서 이 이름으로 고릅니다.
7

버튼 만들기

클릭 한 번으로 페이지를 만들고 양식까지 띄웁니다.

순서하는 일
1DB 위쪽 빈 줄에 /버튼
2이름 : ➕ 새 강의 추가
3작업 ① 페이지 추가 위치 → 강의 DB
4그 옆 칸에서 템플릿 선택 → 템플릿1 ⭐
5속성 편집 → 강의명 = 빈칸 · 상태 = 준비중
6작업 ② 페이지, 양식 또는 URL 열기 → ① 페이지 추가됨 → 중앙에서 보기

설정이 끝나면 작업 줄이 이렇게 보입니다.

눌러서 확인

  • 강의 DB에 새 행이 생긴다
  • 상태가 준비중으로 들어가 있다
  • 페이지가 화면 중앙에 바로 열린다
  • 제목이 비어 있어 강의명을 바로 입력할 수 있다
  • 본문에 양식 네 줄이 딸려 나온다

시트에서 노션으로 보내는 이유

강의 정보는 표에 적는 게 빠르고, 지도안처럼 긴 글은 노션 페이지가 편합니다. 보내는 코드는 시트 안에서 돌아갑니다.

시트강의 정보 적기
→
Apps Script보내는 일꾼 (시트 안의 코드)🔑 API 키를 내고 요청
→
노션지도안 쌓고 일하기창구(API)를 열고 기다림
API 다른 프로그램을 쓰는 정해진 방법 (통로)
API 키 그 프로그램에서 "나"임을 증명하는 열쇠

미리 준비할 것

  • 노션 통합 생성 → 시크릿 키 (ntn_...)
    notion.so/my-integrations 에서 만듭니다
  • DB에 API 연결 추가 — 페이지 우측 상단 ⋯ → 연결
  • DATABASE ID — DB를 전체 페이지로 열기 → 주소의 ?v= 앞 32자리
가장 흔한 실패 — DB에 API 연결을 추가하지 않으면, 토큰이 맞아도 데이터베이스를 찾지 못합니다.

확인

  • 같은 행 재실행 → 건너뜀 1건

대상 : "성인" → "성인 직장인 (AI 도구 처음)"
비고 : 인원 / 환경 / 제약 — 예) 12명 / 태블릿 / 와이파이 불안정
시간이 남으면 — 내 강의의 비고를 바꿔 한 번 더 만들어 보세요. 인원 · 환경이 달라지면 지도안이 어떻게 바뀌는지 비교할 수 있습니다.

안 될 때 확인할 5가지

  1. DB에 API 연결(⋯ → 연결)을 추가했는가?
  2. 속성 이름 = 시트 머리글 = 코드 문자열, 셋 다 똑같은가?
  3. 강의날짜는 YYYY-MM-DD 인가?
  4. 차시는 '텍스트' 타입인가? (숫자 ❌)
  5. 수식(D-day) 속성을 코드가 건드리고 있지 않은가?
I열의 ❌ 메시지를 그대로 복사해서 AI에게 붙여넣으세요. 대부분 바로 고쳐집니다.

503(서버 혼잡)이 나서 다른 Gemini 모델(gemini-flash-latest)로 바꿔도 안 될 때, 또는 403(무료 등급 불가) 이 나면 바로 씁니다.

Groq 키 발급

  • console.groq.com/keys → 가입 → API Key 만들기
  • 각자 자기 계정으로 발급합니다 — 한도가 계정마다 따로라, 한 키를 나눠 쓰면 바로 막힙니다

방법 1 · 시간 여유 있을 때 — 내 코드 고치기 (프롬프트)

고칠 곳은 세 군데입니다 — 상수 2줄 추가 · AI 호출 함수 · 키 확인 부분. 지금까지 쓰던 ChatGPT 대화창에 이어서 붙여 넣으세요.

방법 2 · 시간이 촉박할 때 — 완성 코드로 전체 교체

완성 코드

기존 코드를 모두 지우고 이 코드를 붙여 넣습니다. 맨 위 노션 토큰 · DATABASE ID · Groq 키만 내 것으로 바꾸면 됩니다. 시트의 J열 ID와 노션 페이지는 그대로 이어서 씁니다.

Groq 모델은 바뀝니다. Gemini처럼 latest 별칭이 없어서 모델 ID를 직접 적습니다.
"모델이 없다"는 오류가 나면 console.groq.com/docs/models 의 Production Models에서 글쓰기용 모델을 골라 GROQ_MODEL 만 바꿉니다.
2026년 10월 기준 : openai/gpt-oss-120b (기본) → 안 되면 openai/gpt-oss-20b

작업 규칙

  • 한 번에 기능 하나씩 추가합니다
  • 동작하는 코드는 v1 / v2 / v3 … 로 따로 저장해둡니다
  • AI와는 같은 대화창에서 이어갑니다 (새 창은 기존 코드를 모릅니다)
  • 앞 기능이 살아있는지 확인하고 다음으로 넘어갑니다
  • 15분 넘게 막히면 이 페이지의 완성 코드를 사용합니다
  • 지도안 생성은 한 번에 1~2건씩
