2단계 · 케이스 B

역할 · 기능 · 디자인을 항목으로 나눠 적습니다. 여기까지는 뽑기 기능만 만듭니다.

프롬프트

[역할 부여]
너는 참여형 웹 도구 전문 개발자이자 UI/UX 디자이너야. 모임이나 워크숍 진행자가 현장에서 바로 쓸 수 있는 실용적이고 보기 좋은 웹 앱을 만들어줘.

[작업 목표]
참가자 중 한 명을 공정하게 뽑는 '오늘의 주인공' 웹 앱을 단일 HTML 파일로 제작해줘.

[핵심 기능]
명단 관리: 엑셀이나 메모장에서 복사한 여러 이름을 한꺼번에 붙여넣어  등록할 수 있어야 한다(줄바꿈과 쉼표 모두 구분자로 인식할 것)
중복 방지: '한 번 뽑힌 사람은 다시 안 나오게' 하는 체크박스를 제공한다.  이미 뽑힌 사람은 명단에서 흐리게 표시한다.
셔플 연출: 뽑기 버튼을 누르면 이름이 빠르게 돌아가다가  점점 느려지면서 멈춘다. 2초 정도 끌어서 긴장감을 준다.
진행 상황: '3 / 20 완료' 처럼 지금까지 몇 명이 뽑혔는지 보여준다.  전원이 다 뽑히면 뽑기 버튼이 비활성화된다.
기록 초기화: 뽑힌 기록을 지우고 처음부터 다시 시작하는 버튼.

[디자인 및 기술 제약]
디자인 컨셉:  밝은 종이 무대 위로 부드러운 조명이 내려앉는 느낌, 라이트 세이지 그린 계열에 연한 올리브 색상과 카라멜 브라운 계열 포인트
당첨된 이름은 화면 한가운데에 아주 크게.
가독성: 빔프로젝터로 띄웠을 때 교실 맨 뒷자리에서도 이름이 읽혀야 한다.
  당첨자 이름은 화면 높이의 10% 이상 크기로 할 것.
레이아웃: 왼쪽에 명단 관리, 오른쪽에 무대. 화면이 좁아지면 위아래로 쌓인다.
기술: 외부 라이브러리는 CDN으로만. HTML, CSS, JS를 하나의 파일에 통합할 것.
2단계 결과물 확인

A와 B, 어디가 다른가

명단 붙여넣기 · 중복 방지 · 셔플 · 남은 인원 표시는 A에도 들어 있습니다. 많이들 만드는 앱이라 기본 문장만으로도 나옵니다. 갈리는 건 아래 다섯입니다.

짚을 곳ABB에 뭐라고 썼나
디자인아무 색이나 (파랑 · 흰)지정한 세이지 그린 무대“밝은 종이 무대 … 라이트 세이지 그린”
당첨자 글자최대 46px화면 높이의 15% (최대 230px)“화면 높이의 10% 이상 크기로”
뽑힌 사람 표시안 됨 (명단이 입력창이라 불가)명단에서 흐리게“이미 뽑힌 사람은 명단에서 흐리게”
셔플등속으로 돌다 멈춤점점 느려지며 멈춤“점점 느려지면서 … 2초 정도 끌어서”
전원 완료자동으로 새 라운드뽑기 버튼이 꺼짐“전원이 다 뽑히면 버튼이 비활성화”
CDN 이 뭔가요? 남이 만들어둔 기능을 인터넷에서 불러다 쓰는 방식입니다. 내 파일 안에 그 기능이 없어도, 주소만 적어두면 화면을 열 때마다 가져옵니다. 그래서 파일은 하나로 끝나지만, 인터넷이 끊기면 그 기능은 동작하지 않습니다.
글자 크기를 눈으로 비교해 보세요. 46px 와 230px 입니다. 빔프로젝터에 띄우면 차이가 한눈에 보입니다. “크게” 라고 쓰지 않고 “화면 높이의 10% 이상” 이라고 쓴 결과입니다.
자세히 쓰면 좋은 점만 있는 건 아닙니다. 말로 대충 던지면 AI가 예시 명단까지 알아서 챙겨 줍니다. 항목으로 나눠 적으면 적은 것만 합니다. 그래서 한 번에 완성하려 하지 말고, 돌려보고 빠진 걸 채워가는 겁니다.
여기부터는 기능을 하나씩 얹어 나갑니다. 아래 3·4·5단계는 예시입니다. 그대로 따라 해보셔도 좋고, 본인만의 아이디어를 더해보셔도 좋습니다. 한 번에 하나씩만 바꾸는 것이 요령입니다.

주제 1 · 감성 집중 타이머

상황에 따라 시간과 분위기가 바뀌는 타이머.

단순 프롬프트

상세 프롬프트

[역할 부여]
너는 미니멀리즘을 추구하는 생산성 도구 디자이너야. 작업 공간의 분위기를
차분하게 만들어주는 타이머를 만들어줘.

[작업 목표]
상황에 따라 시간과 분위기가 바뀌는 멀티 모드 타이머를
단일 HTML 파일로 제작해줘.

[핵심 기능]
모드 전환: '집중 25분', '토론 10분', '휴식 5분' 버튼을 제공한다.
  모드를 바꾸면 배경색이 0.6초에 걸쳐 부드럽게 바뀐다.
타이머 조작: 시작, 일시정지, 처음으로 되돌리기.
직접 수정: 시간 숫자를 클릭하면 분과 초를 직접 고칠 수 있다.
종료 알림: 0이 되면 화면 전체가 세 번 깜빡인다.

[디자인 및 기술 제약]
디자인 컨셉: 화이트와 베이지 톤의 깔끔한 배경, 유리 효과가 적용된 타이머 박스.
가독성: 남은 시간 숫자는 화면 높이의 25% 이상 크기로. 회의실 화면에 띄워도 보여야 한다.
기술: 기능을 담당하는 외부 라이브러리는 쓰지 말고 직접 코드로 구현할 것.
  웹폰트는 써도 되지만, 폰트를 못 불러와도 화면이 망가지지 않게
  대체 글꼴을 반드시 함께 지정할 것.
  HTML과 CSS와 JS는 하나의 파일에 통합할 것.

주제 2 · 간단 진단 테스트

질문에 답하면 유형이 나옵니다. 질문만 바꾸면 학습유형 진단, 업무성향 진단이 됩니다.

단순 프롬프트

상세 프롬프트

[역할 부여]
너는 심리 테스트와 인터랙티브 콘텐츠를 만드는 웹 개발자이자 UI 디자이너야.
모임에서 서로 돌려보며 즐길 수 있는 진단 테스트를 만들어줘.

[작업 목표]
질문에 답하면 나만의 유형이 나오는 '진단 테스트'를
단일 HTML 파일로 제작해줘.

[핵심 기능]
기본 데이터: 처음부터 질문 8개와 결과 유형 4개가 들어 있어 바로 해볼 수 있다.
  주제는 '나의 일하는 방식'으로 하고, 유형 이름은
  '새벽형 몰입가'처럼 부르기 좋은 이름으로 지어줘.
질문 진행: 한 화면에 질문 하나씩 보여준다. 선택지는 두 개.
  하나를 고르면 확인 버튼 없이 바로 다음 질문으로 넘어간다.
점수 계산: 선택에 따라 유형별 점수가 쌓이고,
  마지막에 점수가 가장 높은 유형이 결과로 나온다.
결과 화면: 유형 이름, 한 줄 설명, 그리고 잘 맞는 유형과 안 맞는 유형을 같이 보여준다.
다시 하기: 결과 화면에서 처음으로 돌아가는 버튼.

[디자인 및 기술 제약]
디자인 컨셉: 부드러운 파스텔 톤. 질문이 바뀔 때 0.3초 동안 옆으로 밀리며 전환된다.
가독성: 질문 글자는 18px 이상. 폰으로 보는 것을 기준으로 만든다.
레이아웃: 화면 가운데 정렬. 넓은 화면에서도 가운데 폭을 넘지 않는다.
기술: 기능을 담당하는 외부 라이브러리는 쓰지 말고 직접 코드로 구현할 것.
  웹폰트는 써도 되지만, 폰트를 못 불러와도 화면이 망가지지 않게
  대체 글꼴을 반드시 함께 지정할 것.
  HTML과 CSS와 JS는 하나의 파일에 통합할 것.

주제 3 · 밸런스 게임

둘 중 하나를 고르며 넘깁니다. 넷 중 제일 쉽습니다.

단순 프롬프트

상세 프롬프트

[역할 부여]
너는 모임과 파티에서 쓰는 참여형 콘텐츠를 만드는 웹 개발자야.
처음 만난 사람들도 금방 웃게 만드는 도구를 만들어줘.

[작업 목표]
두 선택지 중 하나를 고르며 넘겨보는 '밸런스 게임'을
단일 HTML 파일로 제작해줘.

[핵심 기능]
기본 데이터: 처음부터 질문 15개가 들어 있어 바로 시작할 수 있다.
  누구나 부담 없이 답할 수 있는 가벼운 주제로 만들어줘.
화면 구성: 화면을 반으로 나눠 선택지를 하나씩 놓고, 가운데에 'VS' 를 둔다.
선택: 한쪽을 클릭하면 그 쪽이 커지면서 색이 진해지고,
  0.8초 뒤에 다음 질문으로 넘어간다.
진행 상황: '4 / 15' 로 몇 번째인지 보여준다.
모아보기: 마지막에 내가 고른 것들을 한 화면에 목록으로 보여준다.
